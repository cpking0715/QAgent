## 2. 测试类型要求

| 类型 | 是否必须 | 说明 |
|------|---------|------|
| 功能测试 | 是 | 主流程 + 核心分支 |
| 接口测试 | 是 | 含请求方法、路径、状态码、响应字段断言 |
| 边界测试 | 是 | 文件大小/像素/次数/超时临界值 |
| 异常测试 | 是 | 非法输入、权限不足、服务不可用 |
| 安全测试 | 按需 | 越权、注入、敏感信息 |
| 性能测试 | 按需 | 响应时间 SLA |
| 兼容性测试 | 按需 | 浏览器/分辨率 |
