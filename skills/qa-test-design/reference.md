# ISTQB 测试设计技术参考

本文件供 qa-test-design 技能按需查阅，主指令见 [SKILL.md](SKILL.md)。

## 技术选型速查

| 场景 | 技术 | 要点 |
|------|------|------|
| 输入字段校验 | 等价类 + 边界值 | 有效/无效等价类各至少 1 条；边界取边界值、略低、略高 |
| 计数/时效约束 | 边界值 | 第 n 次锁定覆盖 n-1、n、n+1；时效覆盖临界前后 |
| 多条件规则 | 判定表 | 每组合 1 条，剔除不可能组合 |
| 状态流转 | 状态转换 | 合法转换全覆盖 + 至少 1 条非法转换 |
| 用户旅程 | 场景法 | 主成功 + 备选流 + 异常流 |
| 多维度组合 | pairwise | 代表性组合，禁止全排列 |
| 高风险未知 | 错误推测 | 并发、重放、绕过、注入 |

## 5×5 风险矩阵

- CRITICAL：15–25
- HIGH：10–14
- MEDIUM：5–9
- LOW：1–4

领域提权：支付/权限/敏感信息 → 影响度 ≥ 4。
